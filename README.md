# NumPy Analyzer

## About the Project

NumPy Analyzer is a simple Python project that helps users perform different operations on numerical arrays.

The project uses NumPy and Object-Oriented Programming (OOP) concepts to analyze, sort, search, filter, and perform mathematical operations on data.

It provides a menu-driven interface that makes the program easy to use.

## Features

- Create 1D and 2D arrays
- Display array data
- Calculate sum, mean, median, minimum, and maximum
- Calculate variance and standard deviation
- Find the 25th percentile
- Sort arrays in ascending and descending order
- Search for specific values
- Filter values using a threshold
- Perform addition, subtraction, multiplication, and division
- Calculate dot products for compatible arrays
- Combine and split arrays
- Calculate correlation between two datasets
- Use classes, objects, constructors, and methods

## Technologies Used

- Python
- NumPy

## Requirements

- Python 3.x
- NumPy library
